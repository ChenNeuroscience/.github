## Open Source Tools we've created

| Tool | Role | Files |
| --- | --- | --- |
| <img src="https://raw.githubusercontent.com/ChenNeuroscience/waveform/refs/heads/main/img/icon.svg" width="20" height="20" alt=""><br/> [Waveform](https://github.com/ChenNeuroscience/waveform) | Browser-based viewer and manual cluster editor | Reads `.set`, `.N`, `.pos`, `.cut`, `.clu.N`. | <img src="https://raw.githubusercontent.com/ChenNeuroscience/ltx-klusta/refs/heads/main/assets/ltxk.svg" width="20" height="20" alt=""><br/> [ltx-klusta](https://github.com/ChenNeuroscience/ltx-klusta) | Automatic spike clustering, derived from [KlustaKwik](https://github.com/klusta-team/klustakwik) | Reads `.N`. Writes `.clu.N`. |
| <img src="https://raw.githubusercontent.com/ChenNeuroscience/ephys-rs/refs/heads/main/assets/icon.svg" width="20" height="20" alt=""><br/> [ephys-rs](https://github.com/ChenNeuroscience/ephys-rs) | Recording software, partly derived from [Open Ephys](https://github.com/open-ephys) | Supports writing `.set`, `.N`, `.egf*`, `.pos`, `.ttl`. |
